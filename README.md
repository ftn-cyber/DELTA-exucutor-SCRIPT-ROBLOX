## 📌 Tentang Delta Executor

**Delta Executor** adalah salah satu executor ROBLOX berbasis Android (juga tersedia untuk platform lain) yang memungkinkan pengguna menjalankan script Lua di dalam game. Dengan executor ini, pengguna dapat memanfaatkan berbagai script untuk:

- 🚀 **Auto Farm** — farming otomatis tanpa perlu grinding manual
- 👁️ **ESP / Wallhack** — melihat posisi pemain lain melalui dinding
- ⚡ **Speed Hack / Fly** — bergerak lebih cepat atau terbang
- 💰 **Get Money / Auto Collect** — mengumpulkan mata uang game secara otomatis
- 🎯 **Aimbot / Silent Aim** — di game FPS seperti Arsenal, Phantom Forces
- 🌀 **Teleport** — berpindah lokasi secara instan
- 🔓 **Anti-AFK** — mencegah kick karena idle

## 🛠️ Cara Penggunaan

1. **Unduh & instal Delta Executor** di perangkat Anda.
2. **Login** ke akun ROBLOX Anda melalui Delta Executor.
3. **Masuk ke game** yang ingin Anda mainkan.
4. **Salin (copy) script** yang tersedia di folder `scripts/`.
5. **Paste script** ke kolom eksekusi di Delta Executor.
6. Klik **Execute / Inject** untuk menjalankan script.
7. Menu script akan muncul di layar — pilih fitur yang diinginkan.
